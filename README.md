# 🌐 Personal Portfolio Website

This is my personal portfolio website built using **HTML and CSS**, showcasing my skills, projects, and contact information in a clean and responsive design.

🔗 **Live Demo:**  
https://portfolio-mariyam.netlify.app/

## 📌 Features

- Responsive design for mobile, tablet, and desktop
- Clean and modern user interface
- Smooth navigation across sections
- Project showcase section
- About Me section with profile details
- Contact section for easy communication
